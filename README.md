RUDER — интернет-магазин 

Одностраничный сайт-каталог для бренда RUDER

Проект выполнен с нуля на HTML, CSS и JavaScript без использования готовых шаблонов и фреймворков.

🌊 О проекте

Сайт представляет собой современный каталог товаров с акцентом на визуальную подачу продукции, удобную навигацию и простое взаимодействие с пользователем.

В проекте реализованы:

главная страница с фирменным дизайном;
каталог товаров;
крупные карточки товаров;
категории продукции;
фотографии и описания товаров;
отображение цен;
кнопки перехода к покупке;
интерактивная корзина;
добавление и удаление товаров из корзины;
подсчёт количества товаров;
модальные окна;
адаптированная навигация по странице;
визуальные эффекты и анимации;
аккуратная типографика и работа с отступами;
единый визуальный стиль бренда.
🛠 Использованные технологии

HTML5

семантическая структура страницы;
секции, карточки товаров, навигация;
метатеги и структура документа.

CSS3

Flexbox;
CSS Grid;
переменные CSS;
позиционирование элементов;
адаптация размеров и отступов;
hover-эффекты;
анимации и переходы;
работа с изображениями;
кастомное оформление интерфейса.

JavaScript

интерактивная корзина;
добавление товаров;
удаление товаров;
изменение количества;
открытие и закрытие модальных окон;
обработка действий пользователя;
динамическое изменение элементов страницы.
💻 Особенности проекта

Особое внимание уделено:

визуальной подаче товаров;
структуре каталога;
удобству взаимодействия пользователя с сайтом;
чистому и понятному интерфейсу;
созданию сайта без сторонних фреймворков.

Проект показывает навыки создания полноценного интерактивного сайта с нуля — от HTML-структуры до JavaScript-логики.
