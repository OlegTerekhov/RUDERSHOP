# RUDER Shop

Сайт-каталог бренда RUDER (купальники, бельё, комбинезоны) с интерактивной корзиной.

**Демо:** [olegterekhov.github.io/RUDERSHOP](https://olegterekhov.github.io/RUDERSHOP/)

## О проекте

Каталог бренда одежды с категориями товаров, подробными карточками, корзиной и возможностью перехода к оформлению заказа. Сайт полностью адаптивный и содержит анимации.

## Функционал

- Адаптивная вёрстка
- Каталог товаров с категориями
- Карточки товаров с описанием и ценами
- Интерактивная корзина
- Модальные окна
- Hover-эффекты и анимации
- Переход к оформлению заказа

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)

## Как запустить

Откройте файл `index.html` в браузере.
